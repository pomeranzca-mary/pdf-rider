# PDF Rider

Мобильное приложение для чтения и аннотирования PDF-файлов.
Создано на React Native + Expo.

## Структура проекта

```
pdf-rider/
├── App.js                  # Навигация между экранами
├── app.json                # Настройки проекта Expo
├── package.json            # Зависимости и скрипты
├── babel.config.js         # Конфигурация Babel
├── assets/                 # Иконки и изображения
├── components/             # Переиспользуемые компоненты
│   └── PrimaryButton.js    # Кнопка
├── screens/                # Экраны
│   ├── HomeScreen.js       # Главный экран (список файлов)
│   └── PDFViewerScreen.js  # Просмотр PDF
└── utils/
    └── theme.js            # Общие цвета и отступы
```

## Запуск через Expo Go

1. Установите **Node.js** с сайта https://nodejs.org (версия LTS).
2. Установите приложение **Expo Go** на телефон (App Store или Google Play).
3. Откройте терминал в папке проекта и установите зависимости:

```
npm install
```

4. Запустите проект:

```
npx expo start
```

5. На экране появится QR-код. Отсканируйте его камерой телефона
   (iPhone) или через приложение Expo Go (Android).

Телефон и компьютер должны быть в одной Wi-Fi-сети.

## WhatsApp-режим (Android)

Если QR-код не работает, подключите телефон и компьютер через
одну сеть и нажмите клавишу `a` в терминале, либо используйте
режим туннеля: нажмите `s` и выберите туннель.
